# MNP-CARD Manager FULL

这是完整的网页版 V1，可直接作为静态网站部署。

## 功能
- 首页总览
- 信用卡管理
- 卡号建议只保存后4位
- 有效期、额度、年费、计费周期、还款日、备注
- 每张卡多个固定支出
- 固定支出：名称、金额/月、扣款日、类别、状态、备注
- 自动统计每月/全年固定支出
- 固定支出总表
- 手机号/MNP管理
- MNP日期未来30天提醒
- 搜索、运营商筛选
- JSON备份/恢复
- PWA手机主屏幕安装
- 响应式手机/电脑界面

## 当前数据
本版本开箱即用，数据默认保存在当前浏览器 localStorage。
因此它可以立即使用，但不同设备之间不会自动同步。

## 部署到 GitHub Pages
1. 将本目录文件上传到 GitHub 仓库根目录。
2. Settings -> Pages。
3. Source 选择 GitHub Actions（或 Deploy from branch）。
4. 等部署完成后，得到一个 HTTPS 网站地址。
5. 手机打开网站后，可以“添加到主屏幕”。

## 云端同步
下一步可以接入 Supabase：
- 账号登录
- 云数据库
- 手机/电脑实时同步
- 多设备数据一致
- RLS 权限保护

注意：信用卡安全码(CVV)等敏感信息不建议存入此类网页数据库。建议只保存卡号后4位。
